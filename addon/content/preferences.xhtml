Leave blank to use the addon-managed folder (paper-summarizer/templates under your Zotero data directory), which is created and seeded with the starter templates automatically on startup — your edits there are never overwritten. note.md (and any note-*) are whole-note scaffolds; every other file is an insertable block template (shown in the Template dropdown by filename). Install starter templates… copies the plugin's defaults into the folder (existing files are kept). Default note template The Composer's template picker defaults to this. Can be any template — a whole-note scaffold or a per-annotation/field template (then a generated Summary Note is just that block). Image-annotation folder Relative folder path used when rendering an image (area) annotation into a template — e.g. References/Attachments/{{citekey}}/{{imageBaseName}}. A template can override it with zon: attachments: in its frontmatter. Note: this only affects the embed path text a template renders — the plugin doesn't export image files, and a generated Summary Note doesn't understand ![[…]] wiki-embed syntax, so it shows as literal text rather than an image.
